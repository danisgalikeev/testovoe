# Тестовое задание Frontend — Новостной сайт 500на700

Данный проект выполнен в рамках тестового задания на позицию Frontend-разработчика.

---

## 🔗 Демо

https://testovoe-dg.netlify.app/

---

## 📋 Описание проекта

Реализован блок новостей и детальные страницы новостей на основе предоставленного макета.

Функциональность:

- отображение списка новостей
- переход на детальную страницу новости
- асинхронная загрузка данных
- имитация работы API
- адаптивная верстка
- форма с валидацией и маской

Данные новостей хранятся в локальном JSON-файле и загружаются асинхронно с использованием `fetch`, `useEffect` и искусственной задержки через `setTimeout`, что имитирует работу backend API.

---

## 🛠 Используемые технологии

- Next.js (App Router)
- React
- TypeScript
- SCSS Modules
- Fetch API
- Netlify (deployment)
